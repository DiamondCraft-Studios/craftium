# Reference builds

Drop structure files here: Java `.nbt` or Bedrock `.mcstructure`. They are measured to ground the
craftium-builder skill's proportions (storey heights, roof pitch, window sizes,
mass ratios, material shares).

- Name files `<style>-<thing>`, for example `medieval-cottage.nbt`.
- The structure files are git-ignored (see `.gitignore` here). They are inputs, not
  part of the repo, and may belong to other creators.
- Only measurements and small patterns end up in the skill, never copies of builds.
